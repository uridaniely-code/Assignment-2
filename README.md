# WIS Python Course – Assignments

This repository contains my assignments and exercises for the **Python for Science course** at the Weizmann Institute of Science (October–November 2026).

The purpose of this repository is to document my progress throughout the course, practice programming in Python, and develop good programming habits.

## About Me

I am a Life Sciences graduate student at the Weizmann Institute of Science, interested in biological research and computational approaches to understanding biological systems.

My research interests include neuroscience, microbiology, and the application of computational tools to biological data analysis.

## Course Goals

Through this course, I aim to:

- Strengthen my Python programming skills.
- Improve code organization, readability, and documentation.
- Learn good practices in version control using Git and GitHub.
- Improve data analysis and visualization workflows.
- Develop tools to automate repetitive tasks in scientific research.
- Improve the reproducibility and efficiency of my computational work.
